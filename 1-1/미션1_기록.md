# 미션 1 기록

- AI A 이름 / 주요 대화 캡처 파일명: Codyssey 학습 네이토 / Claude Opus 4.8 / 학습 튜터 (Anthropic). `대화캡처/A_요청.jpg`, `대화캡처/A_답변.jpg`
- AI B 이름 / 주요 대화 캡처 파일명: Codyssey 학습 네이토 / GPT-5.5 / 학습 튜터 (OpenAI). `대화캡처/B_요청.jpg`, `대화캡처/B_답변.jpg`
- AI가 물어서 내가 정한 것:
  - 등급은 S·A·B·C 네 단계로 정했다.
  - 영화 카드를 클릭한 뒤 원하는 등급을 클릭해 옮기도록 정했다.
  - 같은 컴퓨터의 같은 브라우저에서 같은 파일을 다시 열어도 영화 목록과 등급 배치를 유지하도록 정했다.
  - 제공된 영화 8개로 시작하고, 새 영화 제목을 직접 입력해 추가할 수 있도록 정했다.
  - ‘처음으로’ 버튼을 넣고, 확인하면 처음 영화 8개가 모두 미분류인 상태로 돌아가며 취소하면 기존 상태를 유지하도록 정했다.
  - 빈 제목이나 공백만 입력하면 영화를 추가하지 않고 제목 입력 안내를 보여주도록 정했다.
- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과): 아래 표에 정리했다. 초기 화면은 보조 AI도 실제 Chrome에서 확인했고, 기능 동작은 내가 직접 실행하고 이 대화에 보고한 결과다.
- 선택한 파일명과 고른 이유: `영화_B_초안.html`. 두 파일 모두 같은 방법으로 확인한 기능이 정상적으로 동작했다. B는 안내가 있어 더 편했고, 칸과 글씨가 크고 색이 선명해서 보기 편해 선택했다.

- 고치지 않았다면 그대로 둔 이유: 두 파일 모두 기획서의 완성 기준에 따라 직접 확인한 기능이 정상적으로 동작해 수정할 문제를 발견하지 못했다. HTML 코드는 수정하지 않았으므로 수정본 HTML은 없다.

기획 질문과 기획서 정리는 과제 도움 대화의 AI와 진행했고, HTML 제작은 위의 A·B 모델을 사용했다. 두 제작 AI의 새 대화에 같은 기획서와 공통 제작 요청을 전달했다. 공통 요청에는 PDF의 세 문장과 함께, 파일 첨부가 불가능하면 전체 코드를 출력하고 이번 답변에 완성본을 포함하라는 문장을 덧붙였다.

A는 처음에 완성본이 보이지 않아 도구 없이 전체 코드를 직접 출력해 달라는 추가 요청으로 코드를 받았다. B는 초기 답변이 비어 있었고, 이후 기획서 관련 후속 메시지 다음에 코드 응답을 받았다. 각 AI에서 처음 실제로 받은 전체 HTML 코드를 초안으로 저장했다. 두 파일의 코드는 수정하지 않았다.
