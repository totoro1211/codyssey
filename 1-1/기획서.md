# 내 영화 티어리스트 기획서

## 누가 쓰나

- 본 영화를 등급별로 정리하려는 내가 사용한다.
- 학원 동료에게 파일을 보여주고, 정한 기능이 어떻게 동작하는지 설명한다.

## 무엇을 하려고

- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리한다.
- 원하는 영화 제목을 직접 추가하고, 같은 브라우저에서 다시 열어도 정리한 내용을 이어서 사용한다.

## 화면과 동작

- 화면에 S·A·B·C 등급 칸과 미분류 칸을 보여준다. 미분류는 아직 등급을 정하지 않은 영화가 있는 칸이다.
- 처음 열면 제공된 영화 8개가 모두 미분류 칸에 있다.
- 영화 제목이 적힌 카드를 클릭한 뒤 원하는 등급을 클릭하면 해당 칸으로 이동한다. 영화는 한 번에 한 칸에만 있다.
- 제목 입력칸에 새 영화 제목을 쓰고 ‘추가’를 누르면 미분류 칸에 새 영화 카드가 생긴다.
- 제목이 비어 있거나 공백만 있으면 영화를 추가하지 않고 ‘영화 제목을 입력해 주세요’라고 안내한다.
- 영화 목록과 등급 배치를 자동으로 저장한다. 같은 컴퓨터의 같은 브라우저에서 같은 파일을 다시 열면 저장한 내용이 보인다.
- ‘처음으로’ 버튼을 누르면 처음 상태로 되돌릴지 확인한다. 확인하면 추가한 영화를 지우고, 처음 영화 8개가 모두 미분류 칸에 있는 상태로 되돌린다. 취소하면 현재 상태를 유지한다.
- HTML·CSS·JavaScript를 HTML 파일 하나에 담고, 별도 파일이나 서버 실행 없이 브라우저에서 연다. 화면 문구는 한국어로 쓴다.
- 색상과 글꼴, 좁은 화면에서의 구체적인 배치는 아직 정하지 않았다.

## 필요한 자료

학원에서 제공한 아이디어 파일의 영화 제목 8개를 사용한다.

1. 기생충
2. 인터스텔라
3. 라라랜드
4. 센과 치히로의 행방불명
5. 어벤져스: 엔드게임
6. 범죄도시
7. 타이타닉
8. 토이 스토리

## 완성 기준

1. HTML 파일을 브라우저에서 열면 S·A·B·C 칸과 미분류 칸이 보이고, 처음 영화 8개가 미분류 칸에 있다.
2. ‘기생충’ 카드를 클릭하고 S를 클릭하면 S칸에만 표시된다. 이어서 같은 카드를 클릭하고 A를 클릭하면 A칸에만 표시된다.
3. ‘인사이드 아웃’을 입력하고 ‘추가’를 누르면 그 제목의 영화 카드가 미분류 칸에 생긴다.
4. ‘기생충’을 S칸으로 옮기고 새 영화도 추가한 뒤 파일을 닫는다. 같은 컴퓨터의 같은 브라우저에서 같은 파일을 다시 열면 등급 배치와 추가한 영화가 남아 있다.
5. ‘처음으로’를 누르고 확인하면 추가한 영화가 사라지고, 처음 영화 8개가 모두 미분류 칸에 있다. 파일을 다시 열어도 이 초기화된 상태가 유지된다.
6. 영화를 옮긴 상태에서 ‘처음으로’를 누르고 취소하면 영화 목록과 배치가 바뀌지 않는다.
7. 외부 파일을 준비하거나 서버를 실행하지 않고 HTML 파일 하나를 브라우저에서 열어 위 기능을 사용할 수 있다.
8. 제목을 비운 상태와 공백만 입력한 상태에서 각각 ‘추가’를 누르면, 카드 수가 늘지 않고 ‘영화 제목을 입력해 주세요’라는 안내가 보인다.
