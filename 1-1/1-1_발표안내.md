# 1-1 동료평가 · 같은 기획서로 두 결과 비교하기

**내가 한 일** — 영화에 S·A·B·C 등급을 붙이는 페이지를 만들기로 했다. 내가 기능을 정해서 기획서에 적고, 똑같은 기획서를 두 AI에게 줬다. 두 결과를 같은 방법으로 써 보고 더 보기 편한 B를 골랐다.

## 이렇게 말하고 보여 주기

> “영화를 등급별로 정리하고 싶어서, 영화 이동·제목 추가·자동 저장·처음으로 같은 기능을 먼저 정했어요. 같은 기획서를 Claude와 GPT에 줘서 A, B 두 화면을 받았어요. 두 파일에서 같은 행동을 해 보고 비교했어요.”

1. A와 B에서 각각 **기생충 카드 → S 글자**를 누른다. “둘 다 기생충이 S칸으로 옮겨졌고 카드도 한 장뿐이에요.”
2. B 화면에서 안내 문구와 등급 칸을 가리킨다. “둘 다 시험한 기능은 잘 됐는데, B는 안내가 있어 쓰기 편하고 칸과 글씨가 더 크고 색이 선명해서 B를 골랐어요.”
3. 한 가지 더 보여 달라고 하면 B에서 **인사이드 아웃을 추가하고 같은 Chrome에서 같은 파일을 닫았다 다시 연다.** 기생충은 S칸, 인사이드 아웃은 미분류에 남는다.

**질문을 받으면**

- **왜 같은 기획서를 줬어요?** “같은 기능을 부탁해야 결과를 같은 기준으로 비교할 수 있어서요.”
- **직접 한 일은 뭐예요?** “필요한 기능을 정하고 기획서로 정리했어요. AI가 만든 두 파일을 제가 직접 눌러 보고 비교했어요.”
- **수정본은 왜 없어요?** “직접 확인한 기능에서 고칠 문제를 찾지 못해서 받은 초안 두 개를 그대로 제출했어요.”
