# 미션 3 기록

기획서에 따라 먼저 페이지를 직접 사용한 뒤 받은 의견과 대조했다. 동작과 사용 느낌은 학습자가 직접 해 보고 알려 준 결과를 기록했으며, 저장 유지 문제는 보조 AI도 같은 파일과 같은 Chrome 프로필에서 재현했다. 모호한 의견에는 실제로 답변을 받은 것처럼 쓰지 않고, 되물을 질문을 적었다.

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| AI 검토 1: 저장 기능이 없어 파일을 다시 열면 모든 영화가 미분류로 돌아간다. | 기생충을 A칸으로 옮기고 인사이드 아웃을 추가한 뒤 같은 파일을 다시 열자 처음 상태로 돌아왔다. 보조 AI도 같은 파일 주소·같은 Chrome 프로필로 반복해, 닫기 전 9편 중 1편 분류 상태가 재열기 후 8편 중 0편 분류 상태로 돌아가는 것을 확인했다. ‘처음으로’는 누르지 않았다. | 반영 | ‘같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남는다’는 완성 기준과 다르다. 직접 확인한 저장 유지 문제를 개선한다. 내부 코드에 저장 코드가 있는지 여부까지 확인한 것은 아니다. |
| AI 검토 2: ‘처음으로’가 직접 추가한 영화를 지우지 않는다. | 기생충을 A칸에 옮기고 인사이드 아웃을 추가한 뒤 ‘처음으로’를 눌렀다. 처음 영화 8개가 모두 미분류로 돌아왔고, 인사이드 아웃은 사라졌으며 등급 칸도 비었다. | 보류 | 직접 해 본 결과가 받은 의견과 달랐다. 처음 목록과 배치로 돌아가는 동작은 정상적으로 이루어졌다. |
| AI 검토 3: 빈 제목을 막지 않아 글자 없는 카드가 생기며 기획서를 어긴다. | 빈 입력·공백 입력 시험에서 빈 카드가 생겼다. 이후 입력칸을 지운 뒤 공백 세 칸만 넣고 추가했을 때도 빈 카드가 하나 더 생겼다. | 반영 | 빈 카드가 생기는 현상은 확인했다. 다만 기획서에는 빈 제목·공백 입력 금지 조건이 명시되어 있지 않으므로 ‘기획서 위반’이라는 단정은 받아들이지 않는다. 사용 중 불편했던 점으로 빈 카드 방지와 입력 안내를 제안한다. |
| AI의 종합 판단: 위 세 가지 외에는 기획서의 완성 기준을 잘 지킨다. | 창의 가로 폭을 줄였더니 오른쪽이 잘려 ‘처음으로’ 버튼과 등급 칸 끝이 보이지 않았다. | 보류 | 제시된 세 가지 외에도 ‘좁은 화면에서 오른쪽이 잘리지 않는다’는 기준과 다른 현상을 직접 찾았다. 전체 기준을 잘 지킨다는 판단은 그대로 받아들이지 않는다. |
| 동료 의견: 등급마다 색이 달라 S칸을 한눈에 알아볼 수 있다. | S·A·B·C칸의 색이 서로 달라 구분하기 편했다. | 반영 | 직접 사용하며 도움이 된 장점이므로 등급별 색 구분을 유지한다. |
| 동료 의견: ‘8편 중 3편 나눔’ 같은 표시로 얼마나 남았는지 알 수 있다. | 처음 상태에서 기생충을 S칸으로 옮기니 ‘8편 중 1편 나눔’으로 바뀌었다. | 반영 | 전체 수와 분류한 수가 실제 이동 결과에 맞게 표시되었다. 진행 상황을 알려 주는 장점으로 유지한다. |
| 동료 의견: 끌어 놓을 때 칸 색이 바뀌어 어디에 놓이는지 알 수 있다. | 인터스텔라를 A칸 위로 끌어가니 색이 바뀌었고, 놓으니 A칸으로 이동했다. | 반영 | 끌어 놓을 위치를 알려 주는 표시가 실제로 작동하므로 유지한다. |
| 동료 의견: 휴대폰으로 열어 보니 좀 불편했다. | 컴퓨터에서 창 폭을 줄였을 때 오른쪽이 잘리는 현상은 확인했다. 실제 휴대폰에서 시험한 것은 아니어서 동료가 말한 불편이 같은 현상인지는 알 수 없다. | 되묻기 | 질문: 어떤 휴대폰과 브라우저에서, 어느 화면을 보거나 어떤 행동을 할 때 무엇이 불편했나요? 잘린 부분이나 화면 예시를 알려 줄 수 있나요? |
| 동료 의견: 카드 옮기는 게 처음에는 좀 헷갈렸다. | 클릭으로 기생충을 S칸에 옮기고, 끌어 놓기로 A칸에 옮기는 동작은 해 봤다. 하지만 동료가 어느 방법의 어느 단계를 헷갈려 했는지는 설명만으로 알 수 없다. | 되묻기 | 질문: 카드를 클릭한 뒤 등급을 누르는 방법과 끌어 놓는 방법 중 어느 쪽이었나요? 어느 단계에서 무엇을 해야 할지 헷갈렸나요? |
| 동료 의견: 미분류가 아래에 있어 S칸까지 끌려면 스크롤해야 해서 불편하다. 목록이 위나 옆에 있으면 좋겠다. | 미분류의 라라랜드를 S칸으로 끌어 옮겨 보는 과정에서, S칸과 미분류가 한 화면에 보이지 않아 위로 스크롤해야 해서 불편했다. 최종 이동 성공 여부와 별개로 이 불편을 확인했다. | 반영 | 스크롤하면서 끌어야 하는 불편은 확인됐다. 다만 기획서에는 등급 칸이 위, 미분류가 아래라고 정해져 있으므로 위치 변경만 정답으로 삼지 않는다. 기존 배치를 유지하면서도 미분류 근처에서 등급을 선택할 수 있는 방법 등을 제안한다. |
| 동료 의견: 카드 색이 좀 칙칙한 느낌이다. | 칙칙하게 느껴지기는 하지만 제목이 잘 읽히고 카드끼리 구분하기도 쉬웠다. | 보류 | 취향에 관한 의견이고, 현재 색 때문에 읽기나 구분이 어렵다는 문제는 확인되지 않았다. 지금 꼭 바꿀 필요는 없다. |
| 동료 의견: 영화 포스터 사진이 나오면 더 보기 좋겠다. | 제목만으로 어떤 영화인지 알 수 있었고 포스터가 없어도 헷갈리지 않았다. | 보류 | 본 영화를 등급별로 정리한다는 목적에 현재 제목 카드로도 사용할 수 있었다. 기획서에 포스터 제공 조건도 없어 지금 꼭 추가할 필요는 없다. |
| 동료 의견: C칸은 없어도 될 것 같다. | A칸의 인터스텔라를 클릭하고 C 등급을 누르니 C칸에 하나만 남고 A칸에서는 사라졌다. | 보류 | C칸은 실제로 사용할 수 있는 등급이며, 기획서에서 S·A·B·C 네 등급으로 정하기로 했다. 개인적인 선호만으로 정해진 등급을 없애지 않는다. |
| 동료의 종합 판단: 큰 문제는 없어서 PASS를 주겠다. | 저장 유지 실패와 좁은 창의 오른쪽 잘림을 직접 확인했다. | 보류 | 기획서의 완성 기준과 다른 동작이 있어 ‘큰 문제가 없다’는 평가는 그대로 받아들이지 않는다. 제공된 샘플 속 PASS 문구는 내가 실제 동료평가에서 받은 PASS가 아니다. |

- 아무도 말하지 않았는데 내가 찾은 것:
  - 받은 의견과 대조하기 전에, 창 폭을 줄이면 ‘처음으로’ 버튼과 등급 칸 오른쪽 끝이 잘려 보이지 않는 현상을 직접 찾았다. AI 검토에는 이 문제가 빠져 있었다.
  - 동료가 ‘휴대폰에서 불편하다’고는 했지만 무엇이 불편한지는 적지 않았다. 같은 문제를 뜻했을 가능성은 있으므로 완전히 별개의 문제라고 단정하지 않고, 내가 확인한 구체적인 증상을 추가해 기록했다.
  - 저장 유지 실패도 먼저 직접 찾았지만, 받은 의견을 읽으니 AI가 이미 언급한 문제였으므로 ‘아무도 말하지 않은 것’으로 세지 않았다.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: 코랩 세션 질문지는 선택 사항으로 작성하지 않았다.

## 기획서로 먼저 사용해 본 결과

| 해 본 행동 | 실제 결과 |
|---|---|
| 제공된 HTML을 브라우저에서 열고 ‘처음으로’를 누르기 | 외부 파일이나 로그인 과정 없이 페이지가 열렸고, 처음 영화 8개가 모두 미분류에 있었다. |
| 기생충 카드 클릭 → S 등급 클릭 | S칸에 하나만 있고 미분류에서는 사라졌다. |
| 기생충을 S칸에서 A칸으로 끌어 놓기 | A칸에 하나만 있고 S칸에서는 사라졌다. |
| 인사이드 아웃을 입력해 추가하기 | 미분류에 카드가 생기고 기생충의 A칸 배치도 유지됐다. |
| 같은 파일을 같은 브라우저에서 다시 열기 | 처음 상태로 돌아가 배치와 추가한 영화가 유지되지 않았다. 보조 AI도 같은 파일 주소와 같은 Chrome 프로필로 재현했다. |
| 브라우저 창의 가로 폭 줄이기 | 오른쪽이 잘려 ‘처음으로’ 버튼과 등급 칸 끝이 보이지 않았다. |
| 기생충을 A칸에 옮기고 인사이드 아웃을 추가한 뒤 ‘처음으로’ 누르기 | 처음 영화 8개가 모두 미분류로 돌아왔고 인사이드 아웃은 사라졌으며 모든 등급 칸이 비었다. |

민수 님께 보낼 글은 `피드백.md`로 정리했다. HTML 코드는 수정하지 않았다. 실제 GitHub 등록과 학원 동료평가 PASS는 이 기록 작성 시점에 아직 확인하지 않았다.
