# 2-3 동료평가 안내

## 그대로 읽는 말

> 2-3에서는 2-2에서 만든 과제 체크리스트를 써 보면서 불편한 부분을 찾아 고쳤어요. 날짜를 비우면 마감일만 입력하라고 알려주고, Enter로도 과제를 추가할 수 있어요. 화면을 좁히면 과제별 카드가 나오고, 날짜 입력칸 위에도 ‘마감일’이라고 표시했어요. 수정하고 나서 날짜순 정렬과 완료 체크가 잘 되는지 다시 확인했어요.

## 보여줄 순서

1. [체크리스트 v5](%E1%84%80%E1%85%AA%E1%84%8C%E1%85%A6%E1%84%86%E1%85%A1%E1%84%80%E1%85%A1%E1%86%B7%E1%84%8E%E1%85%A6%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%84%89%E1%85%B3%E1%84%90%E1%85%B3_v5.html)를 내려받아 Chrome에서 엽니다. 과목명과 과제 이름만 넣고 ‘추가’를 눌러 **‘마감일을 입력해 주세요.’**가 뜨는 걸 보여 줍니다.
2. 글쓰기 / 독후감 / 2026-11-23을 넣어 Enter로 추가합니다. 통계학 / 3주차 문제 풀이 / 2026-11-20을 추가하면 통계학이 맨 위에 옵니다. 통계학을 완료로 체크해 **남은 과제 2개 → 1개**를 보여 줍니다.
3. 브라우저 창을 좁혀 목록이 카드로 바뀌는 걸 보여 주고, [제작검증기록](%E1%84%8C%E1%85%A6%E1%84%8C%E1%85%A1%E1%86%A8%E1%84%80%E1%85%A5%E1%86%B7%E1%84%8C%E1%85%B3%E1%86%BC%E1%84%80%E1%85%B5%E1%84%85%E1%85%A9%E1%86%A8.md)에서 수정 전후와 테스트 결과를 엽니다.

실제 사용자 테스트를 겸한다면 위 시연 전에 화면을 열고 이렇게 부탁합니다.

> 글쓰기 독후감과 통계학 문제 풀이를 각각 11월 23일, 11월 20일 마감으로 넣고, 더 빨리 마감하는 과제를 완료해 봐 줘. 쓰다가 막히거나 바꾸면 좋겠는 점이 있으면 말해줘.

사용법은 상대가 먼저 시도하도록 두고, 어디에서 멈췄는지와 받은 의견을 적습니다. 의견 하나를 반영하고 다시 확인한 결과를 제작검증기록에 추가합니다.
