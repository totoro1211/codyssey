## 2-3 수정 기록

아래 세 건은 Codex가 브라우저에서 확인하고 하나씩 수정한 결과입니다.

### 수정 1 — 빈 입력 칸 안내 (v1 → v2)

- 발견한 문제 — ‘영어 / 단어 외우기’를 입력하고 마감일만 비운 채 ‘추가’를 눌렀습니다. 마감일을 채우라는 안내를 기대했는데, 세 항목을 모두 입력하라는 안내가 나오고 입력 위치도 마감일로 옮겨지지 않았습니다.
- Codex에 맡긴 수정 내용 — 빠진 항목만 안내하고, 첫 번째 빈 입력 칸으로 커서를 옮깁니다. 안내가 나올 때는 과제 목록에 새 항목을 넣지 않습니다.
- 수정 후 테스트 결과 — Chrome에서 마감일만 비웠을 때 ‘마감일을 입력해 주세요.’가 뜨고 마감일 칸에 커서가 놓였습니다. 과제 2개가 등록된 상태에서 같은 테스트를 하니 목록과 남은 과제 수가 유지됐습니다. 정상 입력으로 추가, 마감일순 정렬, 완료 체크와 해제도 확인했습니다.
- 수정 이유 — 사용자가 이미 채운 칸까지 다시 확인할 필요 없이 빠진 칸을 바로 채울 수 있습니다.

### 수정 2 — Enter로 과제 등록 (v2 → v3)

- 발견한 문제 — 세 항목을 채우고 과제 이름 칸에서 Enter를 눌렀습니다. 과제가 추가될 것으로 기대했는데, 남은 과제 수는 0개였고 목록도 비어 있었습니다.
- Codex에 맡긴 수정 내용 — ‘추가’ 버튼과 입력 칸에서 누르는 Enter가 같은 등록 절차를 실행하도록 고칩니다.
- 수정 후 테스트 결과 — Chrome에서 과제 이름 칸에서 Enter를 눌러 과제 1개를 추가했습니다. 마감일을 비우고 Enter를 누르니 마감일 안내가 나왔고 과제 수는 그대로였습니다. 버튼으로 추가, 마감일순 정렬, 완료 체크와 해제도 확인했습니다.
- 수정 이유 — 키보드로 입력하던 사용자가 마우스로 옮겨서 ‘추가’를 눌러야 하는 불편을 줄였습니다.

### 수정 3 — 좁은 화면에서 과제 읽기 (v3 → v4)

- 발견한 문제 — Chrome에서 화면 폭을 360px로 좁히고 통계학 과제를 넣었습니다. 과제 이름과 마감일이 한눈에 읽힐 것으로 기대했지만, ‘3주차 문제 풀이’는 7줄, ‘2026년 11월 20일’은 4줄로 나뉘었습니다.
- Codex에 맡긴 수정 내용 — 폭이 520px 이하일 때 과제마다 과목명, 과제 이름, 마감일, 완료 체크, 상태를 한 묶음으로 세로 배치합니다. 넓은 화면에서는 기존 표를 표시합니다.
- 수정 후 테스트 결과 — Chrome의 360px 화면에서 가로 스크롤 없이 과제별 카드가 표시됐고, 예시 과제 이름과 날짜가 각각 한 줄에 나왔습니다. 좁은 화면에서 완료 체크와 해제에 따라 남은 과제 수가 2개 → 1개 → 2개로 바뀌었습니다. 넓은 화면의 표, 과제 추가, 날짜순 정렬, 빈칸 안내와 Enter 등록도 확인했습니다.
- 수정 이유 — 좁은 화면에서도 글자가 지나치게 끊기지 않고, 각 과제의 마감일과 완료 상태를 함께 찾을 수 있습니다.

## 2-3 AI 사용성 검토

- 검토자와 작업 — OpenAI Codex가 Chrome에서 과제 두 개를 추가하고, 화면 폭을 360px로 좁힌 뒤 마감일을 읽고 완료로 표시하는 흐름을 확인했습니다.
- 확인한 내용 — 좁은 화면에서 표의 과제 이름과 날짜가 여러 줄로 쪼개졌습니다.
- AI 개선 의견 — 좁은 화면에서는 과제마다 항목 이름과 값을 함께 표시하는 카드로 바꾸면 마감일과 완료 상태를 찾기 쉽습니다.
- 반영 내용과 결과 — 수정 3에서 적용했습니다. 같은 화면 폭에서 날짜와 과제 이름을 한 줄씩 읽을 수 있었고, 완료 표시와 남은 과제 수 변경도 정상 동작했습니다.

### 대학생 상황을 가정한 추가 AI 테스트 (v4)

- 요청한 작업 — 처음 사용하는 대학생을 가정해 글쓰기와 통계학 과제를 등록하고, 마감일이 더 빠른 과제를 완료로 표시했습니다.
- 관찰한 결과 — 통계학 과제가 맨 위에 표시됐습니다. 체크하자 상태에 ‘완료’가 표시됐고, 남은 과제는 2개에서 1개로 줄었습니다.
- AI 피드백 — 날짜 칸에는 연·월·일 형식만 표시됩니다. 입력 칸 위에 ‘마감일’이라고 쓰면 입력할 날짜의 의미를 바로 확인할 수 있습니다.
