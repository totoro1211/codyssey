# 대학생 과제 마감 체크리스트

## 대상 사용자

- 여러 과목의 과제 마감일과 제출 여부를 한곳에서 확인하고 싶은 대학생인 나

## 사용 목적

- 마감일이 빠른 과제부터 확인하고, 제출을 마친 과제를 체크해서 아직 해야 할 과제가 몇 개인지 바로 확인합니다.

## 화면 구성과 동작

- 화면 위에 ‘대학생 과제 마감 체크리스트’라는 제목과 ‘남은 과제 0개’가 표시됩니다.
- 제목 아래에 과목명, 과제 이름, 마감일 입력 칸과 ‘추가’ 버튼이 있습니다.
- 세 칸을 채우고 ‘추가’를 누르면 아래 목록에 과제가 한 줄 생깁니다. 빈 칸이 있으면 입력 안내를 보여 줍니다.
- 목록에는 각 과제의 과목명, 과제 이름, 마감일, 완료 체크 칸이 나옵니다. 마감일이 빠른 과제가 위에 오고, 마감일이 같으면 먼저 추가한 과제가 위에 옵니다.
- 제출한 과제를 체크하면 ‘완료’가 표시되고 남은 과제 수가 1개 줄어듭니다. 체크를 해제하면 남은 과제 수가 1개 늘어납니다. 완료한 과제도 목록에 남습니다.

## 필요한 자료

- 사용자가 입력하는 과목명, 과제 이름, 마감일
- 테스트에 사용할 예시 과제 두 개
  - 글쓰기 / 독후감 / 2026년 11월 23일
  - 통계학 / 3주차 문제 풀이 / 2026년 11월 20일

## 필수 기능

- 과목명, 과제 이름, 마감일을 입력해 과제를 추가합니다.
- 과제를 마감일이 빠른 순서대로 표시합니다.
- 완료 체크를 켜고 끌 수 있고, 남은 과제 수가 바로 바뀝니다.

## 완료 기준

- ‘글쓰기 / 독후감 / 11월 23일’을 먼저 추가하고 ‘통계학 / 3주차 문제 풀이 / 11월 20일’을 나중에 추가해도, 통계학 과제가 목록 맨 위에 나오고 ‘남은 과제 2개’가 표시됩니다.
- 통계학 과제를 완료로 체크하면 ‘남은 과제 1개’가 표시되고, 체크를 해제하면 ‘남은 과제 2개’로 돌아옵니다.
- 마감일을 비운 채 ‘추가’를 누르면 입력 안내가 표시되고 목록과 남은 과제 수는 그대로입니다.
- HTML 파일 하나를 브라우저에서 열면 다른 파일이나 로그인 없이 과제 추가, 정렬, 완료 체크를 사용할 수 있습니다.

## 추가 기능

- 페이지를 다시 열어도 과제 목록과 완료 상태를 볼 수 있도록 저장합니다.
- 등록한 과제의 내용이나 마감일을 수정하거나 목록에서 삭제할 수 있게 합니다.
- 마감일이 임박한 과제를 색으로 강조합니다.

## 한계 및 비목표

1. 이번에는 과제를 저장하지 않아 페이지를 새로고침하거나 닫았다가 다시 열면 목록이 비워집니다.
2. 추가한 과제의 내용을 수정하거나 삭제하는 기능은 이번 범위에서 제외합니다.
3. 마감일이 임박한 과제를 따로 강조하는 기능은 이번 범위에서 제외합니다.

## 검증 방법

- 빈 목록에서 예시 과제 두 개를 11월 23일, 11월 20일 순서로 추가합니다. 마감일을 직접 비교해 적어 둔 순서(통계학 → 글쓰기)와 화면의 목록 순서를 대조합니다. 이어서 통계학 과제를 완료로 체크하고, 체크되지 않은 줄을 직접 세어 화면의 ‘남은 과제 1개’와 일치하는지 확인합니다.
