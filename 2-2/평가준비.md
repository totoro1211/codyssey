# 2-2 동료평가 안내 — 두 AI 비교와 테스트

## 과제에서 요구한 것과 한 일

과제에서는 같은 기획서와 요청을 두 AI에 주고, 두 HTML을 같은 방법으로 테스트한 뒤 하나를 골라 이유와 테스트 3건을 기록하라고 했습니다. 저는 네이토에서 GPT-5.5와 Claude Opus 4.8로 같은 체크리스트를 만들고, Claude 버전을 제출했습니다. [2-2 제작검증기록](../2-2/제작검증기록.md)

## 그대로 읽는 대본

> “2-2에서는 2-1 기획서를 GPT-5.5랑 Claude에 똑같이 줘서 체크리스트 두 개를 만들었어요. 큰 화면에서 둘 다 보기 편했는데, Claude는 표에 ‘마감일’이랑 ‘상태’ 제목이 있어서 필요한 정보를 찾기 편해 골랐어요. 두 버전에서 마감일순 정렬, 완료 체크를 켜고 끌 때 남은 과제 수, 마감일을 비웠을 때 나오는 안내를 같은 방법으로 확인했어요.”

## 화면에 보여줄 순서

먼저 제작검증기록의 **두 AI 비교**와 **선택한 결과물과 근거**를 보여 줍니다. 그다음 GitHub에서 최종 HTML을 내려받아 크롬에서 엽니다. [Claude 체크리스트 HTML](../2-2/과제마감체크리스트_v1.html)

1. **정렬.** 글쓰기 / 독후감 / 2026-11-23을 먼저 넣고, 통계학 / 3주차 문제 풀이 / 2026-11-20을 나중에 넣습니다. 통계학이 위에 나오고 **남은 과제 2개**가 보이는지 보여 줍니다.
2. **완료 체크.** 통계학에 체크했다가 풉니다. 상태에 ‘완료’가 표시되고, 남은 과제 수가 **2개 → 1개 → 2개**로 바뀌는 것을 보여 줍니다.
3. **마감일 빈칸.** 영어 / 단어 외우기를 넣고 마감일은 비운 채 추가를 누릅니다. 입력 안내가 뜨고 과제 목록과 남은 과제 수가 **2개 그대로**인 것을 보여 줍니다.

마지막에 제작검증기록의 **테스트 내용·예상 결과·실제 결과** 표를 열고, 방금 본 동작과 기록이 일치하는지 봐 달라고 부탁합니다.
