## 확인한 결과

- 기능을 추가하기 전에 원본에서 카드 이동, 제목 추가, 저장 후 다시 열기, ‘처음으로’, 좁은 창에서 보기, 빈 제목 입력을 확인했습니다.
- 기능 추가본에서 기생충을 눌러 S칸으로 옮기니 S칸은 0편에서 1편, ‘아직 안 정한 영화’는 8편에서 7편으로 바로 바뀌었습니다. 기생충은 S칸에 한 장만 있었습니다.
- 인사이드 아웃을 추가하니 ‘아직 안 정한 영화’에 카드가 한 장 생기고 8편으로 바뀌었습니다. 같은 Chrome에서 파일을 다시 열었을 때 두 카드의 위치와 숫자가 유지되었습니다.
- 기생충을 S칸에서 A칸으로 끌어 놓으니 S칸은 0편, A칸은 1편이 되었고 기생충은 A칸에 한 장만 있었습니다.
- ‘처음으로’를 누르니 S·A·B·C는 모두 0편, ‘아직 안 정한 영화’는 처음 영화 8편으로 돌아갔습니다. 추가한 인사이드 아웃 카드는 사라졌습니다.
- Chrome 창을 좁혀도 영화 수, 카드 제목, ‘처음으로’ 버튼이 잘리지 않았습니다. 빈칸과 공백만 넣어 각각 추가를 눌렀을 때 모두 안내가 표시되었고 처음 영화 8편만 남았습니다.
- 기능 추가본은 Chrome에서 HTML 파일 하나로 열었습니다. 화면 스타일과 동작 코드도 모두 파일 안에 들어 있었습니다.
