# 1-4 동료평가 · 칸마다 영화 수 표시하기

**내가 한 일** — 제공된 원본이 잘 되는지 먼저 써 봤다. 칸마다 영화가 몇 편인지 보이도록 하고 싶어서, 어떤 숫자가 나오면 성공인지 기획서에 적었다. AI에게 기능을 더해 달라고 한 뒤 새 기능과 기존 기능을 다시 시험했다.

## 옆에 열어 둘 것

- **내가 정한 기준** — GitHub에서 `기획서.md` 맨 아래와 `미션4_기록.md`를 열어 둔다. [GitHub 1-4](https://github.com/totoro1211/codyssey/tree/main/1-4)
- **시연 화면** — 기능을 추가한 HTML을 Chrome에서 열고 ‘처음으로’를 누른다. S·A·B·C는 0편, ‘아직 안 정한 영화’는 8편으로 시작한다. [영화_기능추가.html](https://github.com/totoro1211/codyssey/blob/main/1-4/%E1%84%8B%E1%85%A7%E1%86%BC%E1%84%92%E1%85%AA_%E1%84%80%E1%85%B5%E1%84%82%E1%85%B3%E1%86%BC%E1%84%8E%E1%85%AE%E1%84%80%E1%85%A1.html)

## 이렇게 말하고 보여 주기

> “카드를 하나씩 세지 않아도 어느 칸에 몇 편 있는지 보이면 편할 것 같았어요. 그래서 ‘기생충을 S칸으로 옮기면 S는 1편, 아직 안 정한 영화는 7편이 된다’를 기획서에 먼저 적고 GPT에 요청했어요.”

1. **기생충 카드 → S 글자**를 누른다. “지금 보시면 S는 0편에서 1편, ‘아직 안 정한 영화’는 8편에서 7편으로 바로 바뀌어요.”
2. **인사이드 아웃을 추가**한다. “새 카드가 들어가면서 ‘아직 안 정한 영화’가 8편이 됐어요.”
3. **‘처음으로’**를 누른다. “추가한 카드는 사라지고, 처음 영화 8편과 각 칸의 숫자가 함께 돌아왔어요.”

**질문을 받으면**

- **기존 기능도 다시 확인했어요?** “네. 클릭과 끌어 놓기, 새 영화 추가, 닫았다 다시 열기, 초기화, 좁은 화면, 빈칸 입력을 확인했어요.”
- **원본은 어떻게 했어요?** “원본은 보관하고 AI가 준 코드는 `영화_기능추가.html`이라는 새 파일로 저장했어요. 시험한 기능이 모두 잘 돼 첫 번째 파일을 최종본으로 골랐어요.”
- **만약 원래 기능이 안 됐다면요?** “원본 파일을 다시 첨부해서 새 대화에서 기능 추가를 요청했을 거예요.”
