# 1-2 동료평가 · 영화 카드가 안 옮겨지는 문제 고치기

**내가 한 일** — 제공된 영화 페이지에서 몇몇 카드가 안 옮겨지는 걸 발견했다. 되는 제목과 안 되는 제목을 비교하고, AI에게 이유를 먼저 물었다. 브라우저에서 이유를 확인한 뒤 고쳐 달라고 했고, 같은 카드로 다시 시험했다.

## 옆에 열어 둘 것

- **기록과 증거** — GitHub의 `미션2_기록.md`와 `대화캡처/원인_브라우저확인.png`를 열어 둔다. [GitHub 1-2](https://github.com/totoro1211/codyssey/tree/main/1-2)
- **시연 화면** — 수정 전과 수정 후 HTML을 Chrome에서 각각 연다. 각 화면에서 ‘처음으로’를 누르면 기본 영화로 시작할 수 있다. 제공된 샘플 `영화_수정전.html` · [영화_수정1.html](https://github.com/totoro1211/codyssey/blob/main/1-2/%E1%84%8B%E1%85%A7%E1%86%BC%E1%84%92%E1%85%AA_%E1%84%89%E1%85%AE%E1%84%8C%E1%85%A5%E1%86%BC1.html)

## 이렇게 말하고 보여 주기

1. 수정 전 화면에서 **토이 스토리 카드 → S 글자**를 누른다. “이 파일에서는 토이 스토리가 미분류에 남아요. 기생충은 옮겨져요. 끌어 놓기로도 같은 차이가 있었어요.”
2. 기록이나 검사 화면을 보여 준다. “띄어쓰기 때문인지 보려고 ‘어바웃타임’과 ‘어바웃 타임’을 넣었더니 붙여 쓴 것만 옮겨졌어요. AI에게 이유를 물어보고 브라우저에서 확인하니, 화면에는 ‘토이 스토리’라고 나오지만 카드의 내부 이름표에는 ‘토이’만 들어 있었어요. 그래서 옮길 영화를 못 찾았어요.”
3. 수정 후 화면에서 **똑같이 토이 스토리 카드 → S 글자**를 누른다. “AI에게 카드에 전체 이름표가 들어가도록 고쳐 달라고 했어요. 이제 토이 스토리도 S칸에 하나만 생겨요.”

**질문을 받으면**

- **내부 이름표가 뭐예요?** “화면에 보이는 제목과 별개로, 컴퓨터가 어떤 카드를 옮길지 찾을 때 쓰는 값이에요. 검사 화면에서는 `data-id`로 보여요.”
- **왜 이름표가 잘렸어요?** “이름표 값을 감싸는 따옴표가 빠져 있어서 브라우저가 첫 띄어쓰기 앞까지만 읽었어요.”
- **다른 영화도 확인했어요?** “기본 8편과 직접 추가한 두 제목을 다시 해 봤고, 클릭과 끌어 놓기 모두 됐어요.”
